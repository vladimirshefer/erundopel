# Erundopel (Ерундопель)

**Goal:** Earn the most points by guessing real definitions and fooling others with fake ones.

## Rules

1. Choose a rare word that **nobody knows**. If someone knows it, skip the word.
2. The host keeps the **real definition**.
3. Each player secretly writes one **plausible fake definition**.
4. The host mixes the real definition with all fake ones and presents them anonymously.
5. Each player votes for the definition they think is correct. You **cannot vote for your own**.
6. Reveal the correct definition and score the round.

## Scoring

- **+2 points** — for guessing the real definition.
- **+1 point** — for each player who votes for your fake definition.

After several rounds, the player with the **most points wins**.
